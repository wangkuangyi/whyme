# Walk2 稳定待机与新站序

2026-10-23，分支 `fix/walk-idle-and-order`。本轮只调整走路站的待机收尾和站点顺序，保留已经确认的 Walk2 步态、俯视小全身镜头、配色及到岗小字。

## 修正依据

原先所有站点共用 Idle 源片段 1.5–3.5 秒的往返循环。源 1.5 秒右脚比左脚向前约 33.5 cm，会在走路结束后产生额外探腿。源 2.5 秒双脚前后差约 -2.26 cm，脚踝高度差约 0.65 mm，是更平稳的完整站立姿势。

走路站使用原 Idle 的 2.5 秒完整姿势作为稳定待机，保留 0.55 秒交叉淡化。没有拼接上下半身或手工重设骨骼。点击走路站人物点头后也回到这个站姿；其他三站继续使用原待机循环。原始 GLB、脸、模型、材质、Walk2 源动作均不改动。

顺序为 01 迅速到岗 / Walk、02 审美 / Nod、03 团队 / Wave、04 长期 / LookAround；默认进入 01。各主题的相机与颜色保持，光环节点编号、卡片、首帧、静帧和元数据一并对应新序。

## 验证记录

- 实际 GLB 动作测试 77/77，通过源完整姿态一致性、五分钟待机脚位、点头返回稳站、切到其他站恢复原循环及打断淡入检查。完整姿态与原 Idle 2.5 秒采样最大误差约 `1.19e-7`；收尾最大骨骼变化 `0.0141 m / 帧 @ 240 Hz`，低于原有 `0.02 m` 阈值，没有放宽验收。见 `walk-idle-motion.json`。
- 桌面 1440×900 和手机 390×844 均查看交叉淡化起点、中段、刚停下、停后 0.5 / 2 / 6 秒的实际截图。停下后双脚世界坐标与人物图像保持一致，前后差约 2.26 cm；没有继续播放旧待机的探腿动作。俯角 31.71°、`fill: .56` 保持。

- 首帧、动画待机、原静止模式共 24 张图片及三组元数据已重新生成。10 项视觉摘要检查通过，覆盖双脚稳定、镜头未改变、各站动作对应和 320 px 静帧。见 `walk-idle-visual.json`。
- 生产页面 1440、390、320 px 回归 47/47：默认到岗 01、新目录与配色、到岗小字、团队入口、手机展开、静帧/原静止模式，以及开发页辅助核对动作与介绍早开时序。见 `walk-idle-ui.json`。
- `npm run check`、`npm run build` 通过；仍有 Three.js 场景大 chunk 提示。

上述视觉结论是关键帧采样，不代表逐帧穿模保证。截图及长时序数据在 Git 忽略目录 `output/playwright/walk-idle/`，可用 `capture-walk-idle-frames.cjs` 重生成图片。此前 `walk2.md`、`walk2-*.json` 是上一顺序和待机方案的历史证据，不代表本轮通过。
