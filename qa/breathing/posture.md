# 动作胸背支撑修正

本轮将点头和小幅挥手的胸背支撑线调整到原始 Rest 站姿附近；不改人物网格、4K 原贴图、面部形状或原 GLB 动画数组。仅允许运行时派生姿态的 Spine、Spine1、Spine2、Neck、Head 局部旋转变化，头部世界朝向保持源动作的点头与转头。

## 视觉与参数

同镜头诊断图位于 `output/playwright/posture-diagnosis/`（截图不入库）：

- `v3-nod-1_0-side-before.png` / `v3-nod-1_0-side-support.png`
- `v3-wave-2_0-side-before.png` / `v3-wave-2_0-side-support.png`
- `v3-wave-2_0-station03-before.png` / `v3-wave-2_0-station03-support.png`

station03 对照使用该站的 30° 方位、约 2.86° 仰角和 28° 焦距参数，独立诊断画幅统一为 600×600；它不替代生产页面的布局验收。审阅后选择 support 方案，不添加额外肩骨回收。

以骨盆两侧定义人物矢状面，在原始 Rest 捕获各段支撑角：下段约 −6.710°、中段约 −7.125°、上段约 −5.440°、颈段约 17.354°。点头与挥手目标为原 Rest 的下段/中段，上段取中段 +3°，颈段取原 Rest +1°。分段修正避免把整个人僵硬地向后旋转。各骨最大旋转为 Spine 14°、Spine1 14°、Spine2 20°、Neck 15°；Head 仅抵消继承的旋转，保留源世界朝向。

Nod 第 1 秒的胸椎折角由 20.653° 变为 3°；Wave 第 2 秒由 12.061° 变为 3°。四段源动作扫描中实际最大修正分别为 Nod 17.914°、Wave 9.683°、LookAround 0°、Walk 0°。

## 归位方案

曾验证按已混合姿态动态计算门控会在归位中段重新含胸：Nod 折角回升至 9.144°，Wave 回升至 6.232°。虽然没有位置跳变，视觉方向仍然错误，因此不采用该路径。

最终以 `posture.update({support: 1})` 对 Nod/Wave 的源姿态先校正，再生成运行时派生片段并交给 AnimationMixer 混合至原始 Rest；播放后只调用 `inspect()` 观察，不再对混合结果二次校正。自动门控仅作为源姿态分析工具：中段相对 Rest 后折 4–9° 使用五次 smootherstep，两个端点一、二阶导为零。

## 独立模块验证

执行 `npm run test:posture`，结果见 `correction-results.json`：21 项检查、3,706 个源帧，另有 386 个归位夹具帧、门控边界、极端参数、重复调用和缺轨道检查。

- Nod 0–3 秒、Wave 0.9–4.75 秒、LookAround 1.2–7.4 秒、Walk 0–2.375 秒，240 Hz 取样。
- 允许骨以外的局部旋转以及全部骨的局部位置、缩放不变；下半身世界位置不变。
- 最大头部世界朝向误差约 `1.03e-7 rad`；头部局部补偿最大 12.550°。
- 校正源姿态先混合至 Rest 的独立夹具中，胸椎折角全程不超过 3°；中段对 Rest 最大偏差为 Nod 0.00132°、Wave 0.00323°，没有先弯再直。
- 两个夹具在 240 Hz 下每帧最大骨位置变化约 1.63 / 2.29 mm；最终完全回到原始 Rest。

这些是模块和混合夹具的验证。实际运行时片段采样、收尾时序与连续呼吸由本目录其他报告分别验证；本报告不声称全模型逐帧无穿模。
